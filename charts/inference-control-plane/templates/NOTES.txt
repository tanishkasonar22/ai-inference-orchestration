{{- if .Values.tls.enabled }}

mTLS is ENABLED. Callers need a client cert signed by this release's CA to
connect at all. Extract yours into a git-ignored dir (client-certs/):

  Linux/macOS (bash):
    mkdir -p client-certs
    kubectl get secret {{ .Values.tls.clientSecretName }} -n {{ .Release.Namespace }} -o jsonpath='{.data.tls\.crt}' | base64 -d > client-certs/tls.crt
    kubectl get secret {{ .Values.tls.clientSecretName }} -n {{ .Release.Namespace }} -o jsonpath='{.data.tls\.key}' | base64 -d > client-certs/tls.key
    kubectl get secret {{ .Values.tls.clientSecretName }} -n {{ .Release.Namespace }} -o jsonpath='{.data.ca\.crt}' | base64 -d > client-certs/ca.crt

  Windows (PowerShell -- no native base64 CLI, decode via .NET instead):
    New-Item -ItemType Directory -Force client-certs | Out-Null
    $b64 = kubectl get secret {{ .Values.tls.clientSecretName }} -n {{ .Release.Namespace }} -o jsonpath='{.data.tls\.crt}'
    [IO.File]::WriteAllBytes("$PWD\client-certs\tls.crt", [Convert]::FromBase64String($b64))
    $b64 = kubectl get secret {{ .Values.tls.clientSecretName }} -n {{ .Release.Namespace }} -o jsonpath='{.data.tls\.key}'
    [IO.File]::WriteAllBytes("$PWD\client-certs\tls.key", [Convert]::FromBase64String($b64))
    $b64 = kubectl get secret {{ .Values.tls.clientSecretName }} -n {{ .Release.Namespace }} -o jsonpath='{.data.ca\.crt}'
    [IO.File]::WriteAllBytes("$PWD\client-certs\ca.crt", [Convert]::FromBase64String($b64))

Then point client.py at it: set TLS_CERT_DIR to the client-certs/ path.
{{- else }}

mTLS is DISABLED (tls.enabled=false) -- the API is unauthenticated. Set
tls.enabled=true to require client certs.
{{- end }}
